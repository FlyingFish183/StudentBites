Two subdirectories with a strict one-way dependency direction: `components/` holds presentational React components marked with `'use client'`, while `lib/` contains framework-agnostic utilities. Components import exclusively from `lib/*` (types, api, hooks, nav, format); there are no cross-component imports within this module. `Providers.tsx` is the single entry point that wraps the app in TanStack Query's `QueryClientProvider` with default retry/stale-time settings. The navigation components (`TabBar.tsx` for mobile bottom bar, `SideNav.tsx` for desktop sidebar) both consume the shared `NAV_ITEMS` and `isActive` helper from `lib/nav`. The `StoresMap.tsx` component encapsulates Leaflet/OpenStreetMap initialization via refs and `useEffect`, and must be dynamically imported with `ssr: false`. All data fetching goes through the centralized `api.{get,post,put,del}` wrapper in `lib/api.ts`, which throws a typed `ApiError` class on non-2xx responses.
