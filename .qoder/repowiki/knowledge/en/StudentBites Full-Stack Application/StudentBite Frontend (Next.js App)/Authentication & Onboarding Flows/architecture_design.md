Three Next.js App Router page components under `app/login/`, `app/register/`, and `app/onboarding/`, each declared as a client component via the `"use client"` directive. All HTTP calls go through a shared `@/lib/api` client (`api.post`, `api.get`, `api.put`) which throws typed `ApiError` instances; successful mutations invalidate the `me` query key via `@tanstack/react-query`'s `useQueryClient` before navigating with `next/navigation`'s `router.replace`. The login and register pages are single-purpose forms that redirect to `/` or `/onboarding` respectively, while the onboarding page implements a local step-based wizard (body stats → goal → budget) driven by React `useState` and pre-fills existing data from a `/profile` GET when available. UI constants like `ACTIVITY_LABELS`, `GOAL_LABELS`, and types `ActivityLevel`, `Goal`, `IProfile` are imported from `@/lib/types`, and currency formatting uses `formatVnd` from `@/lib/format`.
