Built as a Next.js App Router route group `(main)` that shares a single client-side `layout.tsx` enforcing authentication via the `useMe()` hook — unauthenticated users are redirected to `/login`, and a bottom `TabBar` is rendered for all child routes. Each route (`page.tsx`) is a standalone client component (`"use client"`) that fetches data through the shared `@/lib/api` client using `@tanstack/react-query` hooks (`useQuery`/`useMutation`). The root `page.tsx` acts as the dashboard hub, pulling daily stats, plan, and logs, then delegates detailed views to `/planner`, `/stores`, and `/history`. Cross-cutting concerns (API calls, formatting helpers, TypeScript types) live in `@/lib/*`, while UI primitives like `ProgressBar` and the Leaflet-based `StoresMap` (loaded via `next/dynamic` with `ssr: false`) are imported from `@/components`.
