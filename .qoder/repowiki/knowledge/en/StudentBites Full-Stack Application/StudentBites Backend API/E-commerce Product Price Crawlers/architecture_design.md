The module follows a pluggable crawler pattern centered on the `ICrawler` interface in `common.ts`, which defines a `sourceSite` string and a `crawl()` method returning `IRawProduct[]`. Each site-specific crawler (`bachhoaxanh.ts`, `winmart.ts`, `coopmart.ts`) implements this interface by fetching category pages with axios, parsing HTML via cheerio (or extracting JSON from Next.js `__NEXT_DATA__` for WinMart), and normalizing results into the shared `IRawProduct` shape. The `runner.ts` orchestrates execution: it registers all crawlers in a `CRAWLERS` array, loops through them sequentially via `runAllCrawlers()`, and delegates persistence to `saveProducts()` which matches products to ingredients by longest keyword match and upserts `ingredientPrice` records through Prisma. Scheduling is handled by `node-cron` at 2 AM daily via `scheduleCrawlers()`, and the same file also serves as a CLI entry point when invoked directly (`npm run crawl`). Dependency direction is one-way: crawlers depend on `common.ts` for types and utilities; `runner.ts` depends on all concrete crawlers; nothing imports back from runners.
