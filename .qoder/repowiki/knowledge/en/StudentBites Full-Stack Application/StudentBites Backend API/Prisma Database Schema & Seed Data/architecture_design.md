Single-file Prisma schema (`schema.prisma`) declares four enums (`ActivityLevel`, `Goal`, `MealType`, `StoreType`) and nine domain models: `User` → `Profile` (one-to-one), `Dish` ↔ `Ingredient` via join table `DishIngredient`, `Ingredient` ↔ `Store` through `IngredientPrice`, and user-centric planning/logging via `MealPlan` → `MealPlanItem` and `MealLog`. Relations use explicit `@relation` fields with `onDelete: Cascade` for referential integrity. The datasource targets PostgreSQL with `DATABASE_URL` from environment. A separate `seed.ts` script uses the generated `@prisma/client` to upsert ingredients, three online stores (bachhoaxanh, winmart, coopmart), their price references, and ~20 pre-defined dishes with computed macro/nutrition values. Migrations live under `migrations/` with a `migration_lock.toml` pinning the PostgreSQL provider.
