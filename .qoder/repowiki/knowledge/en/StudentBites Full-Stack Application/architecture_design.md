Two sibling child modules form the system: `frontend_studentbite` (Next.js App Router) consumes the `backend` (Express REST API) over HTTP, sharing domain concepts such as user profiles, meal plans, and logging. The backend owns data persistence via Prisma + PostgreSQL and exposes the only source of truth for auth, meal planning, and stats; the frontend handles UI routing, TanStack Query caching, and React Hook Form validation. Cross-child communication is strictly client-server via REST endpoints — there is no shared code or library between the two.
